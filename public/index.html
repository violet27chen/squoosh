图片转换 API

零服务器 · 按需图片缩放 / 转格式 / 压缩 · 改 URL 即得图

怎么用？

只要在图片地址前面拼上变换参数，就能实时得到处理后的图。把它直接放进 <img src="..."> 即可。

https://你的域名/image/width=400,quality=70,format=webp/sample.png

抓网上任意一张图来转换，加 ?url=：

https://你的域名/image/width=800,quality=80,format=webp?url=https://example.com/photo.jpg
常用参数
想干啥写法
缩到指定宽度width=400
转成 WebP（省体积）format=webp
自动选最佳格式format=auto（默认）
控制画质quality=70
裁剪填满fit=cover
