Squoosh Transform

把 Squoosh 项目改造成的自托管按需图像变换服务（类 Cloudflare Images），运行在 EdgeOne Makers 的 Node Functions 上，不锁任何云厂商。

引擎 sharp/libvips URL 即 API 本地图 + 公网 URL 边缘缓存

调用方式

URL 格式（选项用逗号分隔，写在路径里）：

/image/<options>/<path>       本地图片
/image/<options>?url=<公网图片>   公网图片

示例：

# 把 sample.png 缩到宽 800、质量 80、转 webp
/image/width=800,quality=80,format=webp/sample.png

# 响应式：按浏览器能力自动选 avif/webp，最大边 1200
/image/fit=scale-down,width=1200?url=https://example.com/photo.jpg

支持的参数

参数说明可选值 / 默认
width / height目标尺寸（像素）数字；缺省则不缩放
fit适配模式scale-down(默认,不放大) / contain / cover / crop / pad / fill / outside
format输出格式auto(按 Accept 协商) / webp / avif / jpeg / png / original
quality有损质量 1-100webp/jpeg 默认 80，avif 默认 50
dpr设备像素比，乘到 width/height数字，如 2
backgroundpad 模式的填充色hex，如 ffffff
gravity裁剪对齐center / north / south / east / west 及四角
blur模糊强度 1-2000（0=关）数字
sharpen锐化开关出现即为开
rotate旋转角度（默认按 EXIF 自动转正）数字，如 90
metadata保留元信息默认剥离；keep 保留 EXIF/ICC
